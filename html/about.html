ABOUT • THE PROJECT

A clearer view of your repository.

RepoXray brings GitHub repository information into one place, helping you explore code activity, commits, and contributors through a simple interface.

Our Purpose

Understanding a repository often involves looking through different types of information. RepoXray aims to bring useful repository insights together in a clear and accessible interface.

SIMPLICITY FIRST

What We Explore

RepoXray focuses on repository activity, commit history, contributor information, and code frequency when that information is available.

REPOSITORY INSIGHTS

Who It's For

Students, developers, and engineering teams who want an organized way to explore public GitHub repositories and better understand their activity.
