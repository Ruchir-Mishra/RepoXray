About RepoXray

A simple way to understand GitHub repositories through code activity, commits, and contributor insights.

Our Purpose

RepoXray helps developers explore repository activity and understand how a project evolves over time.

What We Analyze

Explore commit history, contributor activity, and code frequency to gain useful insights into a repository.

Who Is It For?

Students, developers, and teams who want a clearer view of GitHub projects in one place.
